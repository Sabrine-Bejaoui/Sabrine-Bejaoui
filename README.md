## Featured projects

**[FraudLens — Financial Fraud Detection & Investigation Platform](https://github.com/Sabrine-Bejaoui/FraudLens-Platform)**
Multi-organization web platform that turns transaction files into prioritized, explained fraud alerts and supports analysts through investigation and decision-making. Compares Random Forest, XGBoost, LightGBM, Logistic Regression and Isolation Forest on a highly imbalanced public dataset, with SHAP explanations, data validation, drift monitoring and an audit history.
*Python · FastAPI · PostgreSQL · scikit-learn · XGBoost · LightGBM · SHAP · React · TypeScript* — public showcase; source code is private.

**[IntelliHire — Intelligent Recruitment Assistant](https://github.com/Sabrine-Bejaoui/IntelliHire-Intelligent-Recruitment-Assistant)**
Parses PDF resumes, extracts skills with NLP (spaCy) and ranks candidates against job offers using TF-IDF, BM25 and Sentence Transformers, with an explanation of matched and missing skills.
*Python · spaCy · Sentence Transformers · FastAPI · PostgreSQL · React · TypeScript*
