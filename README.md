# Sabrine Bejaoui

Master's student in Data Science and Decision Support Systems at the Higher Institute of Management of Bizerte, with a Business Intelligence background.

I am interested in the point where data becomes a decision: reliable data pipelines, machine learning and NLP models, and dashboards that people can act on.

## Focus areas

- **Machine Learning:** predictive modeling and time series forecasting
- **Natural Language Processing:** text extraction, named entity recognition, semantic similarity
- **Business Intelligence:** ETL, data warehousing, KPI dashboards

## Featured project

**[IntelliHire — Intelligent Recruitment Assistant](https://github.com/Sabrine-Bejaoui/IntelliHire-Intelligent-Recruitment-Assistant)**
Parses PDF resumes, extracts skills with NLP (spaCy) and ranks candidates against job offers using TF-IDF, BM25 and Sentence Transformers, with an explanation of matched and missing skills.
*FastAPI · PostgreSQL · React · TypeScript · Docker*

## Experience

- **Business Intelligence Intern, LEONI Wiring Systems (2025):** replaced paper-based productivity reporting with a real-time monitoring solution built on ETL pipelines, a data warehouse, a web application and KPI dashboards.
